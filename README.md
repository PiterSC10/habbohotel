# 🏨 HABBO HOTEL · Manual Operativo

### Panel interno · Rangos · Reclutamiento · Formación · Procedimientos

Proyecto web desarrollado como **manual operativo y panel de consulta para Habbo**, diseñado para centralizar de forma clara la información necesaria durante la actividad dentro de la organización.

👤 **Proyecto de:** `pEdRodeRHueLiN`  
🔖 **Firma:** `10P`

---

## 🎯 Objetivo

El objetivo de esta web es reunir en un único lugar toda la información necesaria para consultar rápidamente procedimientos, rangos, ascensos, comandos y funcionamiento interno.

Está diseñada para utilizarse como herramienta de apoyo durante la actividad en Habbo, evitando tener que buscar constantemente información en diferentes documentos.

---

## 📚 Contenido

La plataforma organiza la información en diferentes apartados:

- 👤 Reclutamiento
- 🎓 Formación
- 📦 Logística
- 🛡️ Seguridad
- ⭐ Supervisión
- 📈 Rangos y ascensos
- 💰 Pagos
- 🏅 Placas y beneficios
- ⌨️ Comandos
- ❓ Preguntas frecuentes
- 📋 Procedimientos internos

---

## 👮 Sistema de progresión

La web permite consultar de forma sencilla la progresión de rangos y los requisitos asociados a cada puesto.

### Inicio

`Pasante → Agente I → Agente II → Agente III`

Una vez completada esta etapa comienza la progresión hacia los siguientes puestos y departamentos.

Cada área dispone de sus propios procedimientos, tiempos y responsabilidades.

---

## ⌨️ Comandos

La plataforma sirve también como referencia rápida para los principales comandos utilizados durante la actividad.

Ejemplos:

` :time ` · ` :autotime ` · ` :comandos ` · ` :pasar ` · ` :sacar `

Los comandos disponibles pueden variar dependiendo del rango y puesto ocupado.

## 🔒 Seguridad

Este proyecto puede incluir zonas destinadas únicamente a miembros autorizados.

La información sensible, contraseñas reales o credenciales personales **nunca deben almacenarse directamente en un repositorio público ni dentro del código cliente**.

El sistema de acceso incluido en una web estática debe considerarse únicamente una barrera visual y no un sistema de autenticación seguro.
